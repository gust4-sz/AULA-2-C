# Linguagem C — Exercícios de Nível Intermediário

Nesta atividade, foram desenvolvidos exercícios de nível intermediário na linguagem **C**, com foco no aprimoramento da lógica de programação e no uso de estruturas condicionais, estruturas de repetição e validações.

## 📚 Conteúdos estudados

* Média ponderada e validação de dados
* Variáveis e tipos de dados
* Operadores aritméticos, relacionais e lógicos
* Estruturas condicionais (`if`, `else if`, `else`)
* Estrutura de repetição `for`
* Estrutura de repetição `while`
* Uso de contadores e acumuladores
* Validação de entradas
* Operador módulo (`%`)
* Manipulação de caracteres e strings
* Verificação de números primos
* Sequência de Fibonacci
* Criação de menus interativos
* Resolução de exercícios práticos

## 💻 Atividades

Foram desenvolvidos exercícios envolvendo:

* Cálculo de média ponderada com validação
* Identificação do maior e menor valor e cálculo de média
* Contagem de alunos aprovados, em exame e reprovados
* Classificação de triângulos
* Tabuada utilizando `for` e `while`
* Contagem de vogais e consoantes
* Verificação de números primos
* Calculadora com menu e repetição
* Sequência de Fibonacci
* Validação de números dentro de uma faixa específica

## 🎯 Objetivo

Aprimorar os conhecimentos da linguagem C e desenvolver a capacidade de resolver problemas utilizando **condições, repetições, contadores, acumuladores e validações**, fortalecendo a lógica de programação por meio de exercícios práticos.
